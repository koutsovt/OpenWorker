# Scenario: Research Ethics eForms Modernisation

A proof-of-concept scenario for the agent workforce. **Everything in `knowledge/` is simulated.**
The systems, volumes, requirements and prices were written for this exercise; they describe no real
system and are not real quotes. The platform connects to nothing: agents can only search and read
these files.

```bash
node --env-file=/path/to/private.env --disable-warning=ExperimentalWarning src/cli/main.ts orchestrate --scenario scenarios/research-ethics-eforms
```
