# Capability gap analysis

Use this method to find out, before a new kind of work is planned, whether the approved agents and
skills can do it, and what would have to be added if they cannot.

## Method

1. **Read the work.** Search the documents for what is being decided, what must be designed or
   checked, the constraints, and the risks the authors name. Read the passages in full; cite them.
2. **List the needs as capabilities.** A need is a kind of analysis, design or checking the work
   requires: "appraise options on comparable costs", "design role-based visibility of restricted
   fields", "trace a process to the industrial agreement". Group requirements that call for the same
   capability into one need. Aim for eight to twenty needs.
3. **Match each need to the catalogue.** Read each skill's purpose, scope and outputs, and each
   agent's purpose. A need is *covered* when an agent's purpose includes it and one of its eligible
   skills gives a method for it; *partial* when the agent fits but no skill gives the method, or the
   skill covers only part; a *gap* when no agent's purpose includes it.
4. **Recommend the smallest change** for every partial or gap, in this order of preference:
   - an existing skill made eligible for another agent (*extend-agent*);
   - a new skill for an existing agent whose purpose fits (*new-skill*, naming the agent);
   - a new agent, only when the need is outside every agent's purpose (*new-agent*), saying which
     skills and which read tools it needs. Give its skills as *new-skill* recommendations too.
   Reuse one recommended id for every need it serves.
5. **Rank** each need: *high* if the work's main decision depends on it, *medium* if a material
   part does, *low* otherwise.
6. **Check classification.** Note documents or data the work needs that are likely confidential or
   restricted, when the agents and tools are classified lower.

## Rules

- Judge coverage from what a skill says it does, never from a similar-sounding name.
- Do not recommend a change for a need that is covered.
- A recommendation describes what the skill or agent must do; it is a draft for a person to write,
  review and approve, not a definition.
